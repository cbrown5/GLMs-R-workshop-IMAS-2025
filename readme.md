## Directories and files

### Project Structure


### File Descriptions

**Data Files:**
- `ConsistencyData.csv` - Dataset for consistency analysis
- `CopepodData.csv` - Copepod ecological data
- `grasses.csv` - Grass species data
- `shark1.csv` - Shark research data
- `ZooBiomass.csv` - Zooplankton biomass measurements

**Scripts:**
- `linear-model.R` - Contains linear modeling examples and exercises
- `model-selection.R` - Contains model selection techniques and comparisons
